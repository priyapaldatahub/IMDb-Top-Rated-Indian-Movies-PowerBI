# 🎬 IMDb Top Rated Indian Movies Analysis & Power BI Dashboard

---

## 📌 Project Overview

This project is an end-to-end **Data Analytics and Business Intelligence project** focused on analyzing IMDb Top Rated Indian Movies.

The project starts with collecting movie information through web scraping using **Python, Selenium and BeautifulSoup**. The scraped data is then cleaned and analyzed using **Pandas, NumPy, Matplotlib and Seaborn**.

The cleaned dataset is finally used to build a professional **3-page interactive Power BI dashboard** to analyze movie ratings, genres, directors, actors, runtime, audience votes and release trends.
